6.2 Building Your First Agent in Base44

A full build-along — the agent use-case you chose in 6.1, built and working.

Before you start this lesson

  • Your 3.3 client pipeline or operations app — this agent connects to it
  • The use-case you chose in 6.1

This follows the same build pattern as 3.1 and 2.2 — describe it precisely, let Base44 build it, test it by hand, fix it in plain English. If those two builds felt natural by now, this one should too.

Base44 step Open your 3.3 Client Pipeline app (or a duplicate of it for this exercise) and paste the prompt below, adjusted for the use-case you picked in 6.1.

The prompt (example: follow-up nudge agent)

Base44 build prompt select all, adapt to your chosen use-case, paste into Base44 
Add an automated follow-up agent to this app.

It should:
- Check daily for any contact whose Status is "New Lead" or "Contacted" with no update in the last 3 days
- For each one, automatically send a short, friendly follow-up email or log a reminder for me to send one (whichever this tool supports)
- Log every automated follow-up in the contact's Notes field with a timestamp, so I can see what was sent and when
- Never send more than 2 automated follow-ups to the same contact without me reviewing it first

Keep the message tone friendly and low-pressure, not pushy.

Steps

  1. Paste the prompt (adapted to your 6.1 use-case) into your app.
  2. Create a test contact with an old "last updated" date to trigger the follow-up condition.
  3. Confirm the agent actually fires — check the Notes log for the automated entry.
  4. Publish.
What you should have when this lesson is done A working, published agent inside your operations app, confirmed to fire correctly against a test contact.
