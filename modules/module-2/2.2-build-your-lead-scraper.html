2.2 Build Your Lead Scraper in Base44

A real, working app that pulls local businesses matching your niche — built start to finish, on the same tool as everything else in this course.

Before you start this lesson

  • A free Google Places API key — about 5 minutes: Google Cloud Console → enable the "Places API" → create a key. Google's free tier easily covers this course.
  • Your shortlist of 3 candidate niches from 2.1

This is the second hands-on Base44 build in the course, and it's the one that keeps you off paid scraper tools entirely — one tool, one skill, reused for everything.

Base44 step Open a new Base44 project and paste the prompt below. When it asks how to fetch business data, connect the Google Places API key you generated above.

The prompt

Base44 build prompt select all, copy, paste into Base44 
Build me an app called "Lead Finder."

It should have:
- A search form with two fields: Business Category and Location (city or zip code)
- When I submit the form, search for matching local businesses using the Google Places API and show the results
- Save every search's results into a persistent "Leads" table so results aren't lost between searches
- Each lead should store: Business Name, Address, Phone, Website (if available), Category, and a Status field (New, Contacted, Demo Booked, Won, Lost)
- Let me edit the Status directly from the results table
- Let me filter/sort the Leads table by Status and by which search/category they came from

Keep it simple and fast to use — this is a working tool I'll use weekly, not a demo.

Steps

  1. Paste the prompt into a new Base44 project.
  2. When prompted for a data source or API connection, provide your Google Places API key.
  3. Run a real search for your top candidate niche (from 2.1) in your actual area.
  4. Check the results by hand — do these look like real, contactable businesses? If the API returns something odd, describe the problem back to Base44 in plain English rather than editing anything manually.
  5. Publish the app once it's returning clean results.
What you should have when this lesson is done A published Lead Finder app with at least 15–20 real leads pulled for your top candidate niche.
